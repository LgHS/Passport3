SIL Open Font License 1.1 (https://openfontlicense.org). Same typeface as the site itself
(@fontsource/open-sans), kept here as a TTF because the avatar renderer (resvg) can't read WOFF.
Used only to draw the initials of generated avatars (src/lib/server/initialsAvatar.ts).
